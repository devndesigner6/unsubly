ESCROW VAULTS + A2A AUTONOMOUS AGENT
Segment: 2:15 – 4:00  ·  The core blockchain innovation
2:15–2:35
"Now for the core innovation — Escrow Vaults. These are real Algorand smart contracts deployed directly from this UI. Navigate to Escrow Vaults to see all created vaults. Each vault shows its on-chain address, current ALGO balance, status, and vault type."
Navigate to /escrow-vaults — show the vault list with their statuses (Active, Funded, Released)
2:35–3:00
"Let me create a new vault. I'll click Create Vault. Unsubscribely supports five vault types: Standard, Time-Locked, Multi-Signature, Dispute, and ASA token vaults. For this demo I'll select Standard — watch for the green banner that says Agent Auto-Release Enabled. This means an autonomous agent has been granted permission to release this vault automatically on the billing date."
Click Create Vault → Select "Standard" → point clearly to the green "Agent Auto-Release Enabled" banner → fill in recipient address and amount → click Deploy
3:00–3:20
"The smart contract is now deploying on Algorand testnet. The wallet prompts for signature — once confirmed, the contract gets a unique on-chain application ID. Let me click into this vault to see its details. Here we can see the contract address, the agent address that has release permissions, on-chain balance, and full transaction history."
Sign the wallet transaction → wait for confirmation → click into the new vault's detail page → point to App ID, Agent Address, and transaction list
3:20–3:40
"Now I'll fund the vault. I click Fund, enter an ALGO amount, sign with my wallet — and the funds are now locked inside the smart contract on-chain. The vault status updates to Funded. No one can touch these funds without authorization — not even me — unless through the contract's release logic."
Click Fund → enter amount (e.g. 1 ALGO) → sign wallet → show vault balance updating to "Funded" status
3:40–4:00
"This is the A2A magic. Our autonomous agent — running as a Supabase Edge Function — checks every vault daily. When a subscription billing date arrives, the agent signs and sends the release transaction using its own wallet, paying from the vault to the recipient automatically. No user action needed. This is true Agent-to-Agent autonomous payment on the Algorand blockchain."
Go back to dashboard → point to the Agentic Activity log → show an auto-release entry → click the Lora Explorer link to show the live on-chain transaction
Critical Points for Judges
  • Clearly say "Agent Auto-Release Enabled" banner — this is the A2A differentiator
  • Show the agent address in vault details — it's different from your wallet (autonomous agent)
  • Click the Lora Explorer link to prove it's a REAL on-chain transaction, not mocked
  • If wallet signing fails, have a pre-funded vault ready to fall back to
